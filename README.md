# Mapa de Oportunidades Térmicas

Prototipo técnico-comercial interactivo de **Calor Rescatado** para explorar, configurar y priorizar oportunidades de aprovechamiento de calor residual.

## Ejecutar

No requiere instalar dependencias. Desde la raíz del repositorio:

```bash
python3 -m http.server 4173
```

Abra `http://localhost:4173` en un navegador.

## Alcance

- Vista aérea ilustrativa con fuentes y demandas seleccionables.
- Compatibilidad fuente-demanda y rutas de valorización.
- Tecnologías y modelos CAPEX, ESCO, BOOT y energía como servicio.
- Escenarios conservador, base y optimista.
- Cálculo de potencia útil, energía, ahorro, CAPEX, payback y CO₂.
- Ranking, portafolio, matriz de compatibilidad y ficha descargable.

Todos los datos, ubicaciones y cálculos son demostrativos. La imagen de planta es una ilustración generada para este prototipo; no representa la disposición real de la Refinería de Cartagena.
